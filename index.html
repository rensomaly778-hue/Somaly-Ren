English

Lesson: Passive Voice

We use passive voice when the action is more important than the person who does the action.

Structure:

Subject + be + Past Participle (V3)

Examples:

Active: IT workers make websites.

Passive: Websites are made by IT workers.

Active: People use computers.

Passive: Computers are used by people.

Active: They build websites.

Passive: Websites are built by them.

Algorithm

Lesson: If / Else Condition

An algorithm is a step-by-step method used to solve a problem.

Example:

We want to check if a student passes or fails. 

score = 75

if score >= 50:
    print("Pass")
else:
    print("Fail")

Result:

Pass

Algorithm Steps:

  1. Input the student's score.
  2. Check if score is 50 or higher.
  3. If yes → Pass.
  4. If no → Fail.
